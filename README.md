# Retirement Planner

Single-file retirement calculator: grows a 401k to retirement, adds healthcare and Medicare, grosses up for federal and Ohio taxes (including school district tax), models Social Security claim age, RMDs, and Coast FIRE, then draws the balance down.

Open `index.html` in any browser, or use the GitHub Pages site. Nothing is stored or sent anywhere; everything runs in the browser.

Planning estimates only, not financial advice.
